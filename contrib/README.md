# `contrib` folder
This folder contains external configuration for building images and run the 5 minute tutorial. 
You will find: 

- db: a init script to initialize postgres with multiple databases, used in the main docker-compose file
- docker-hub-sdk: a generated SDK for dockerhub (see package.json for generation script)
- docker-hub-api.yaml: Open Api v3 specification for docker-hub api.
- nginx: example configuration for the quickstart
